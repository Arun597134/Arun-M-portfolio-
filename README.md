### 🚀 Core System Capabilities

* **🤖 Horizontal AI Robot Traveler**:
  * Decoupled tracking system that synchronizes a traveling robot traveler on the navbar.
  * **Desktop**: Maps scroll progress interpolation to custom coordinates.
  * **Mobile**: Uses link-container button offsets for button-mapped coordinate tracking.
* **🏆 Stepped Podium & 3D Trophies**:
  * An interactive competition-style podium with stepped heights aligned at the base (`align-items: end`).
  * Custom-drawn volumetric 3D trophies (Coding Cup, Plaque Shield, Laurel Wreath, Star Monument) featuring metallic gradients, depth shadows, and a continuous slow-yaw rotation (`rotateY: [0, 15, -15, 0]`).
* **🧠 Symmetrical Knowledge Network**:
  * A symmetrical, vector-connected network board linking your portrait to interactive cards.
  * Uses a dynamic, swiping scale wrapper on mobile viewports so users can swipe to explore the full board.
* **💬 Holographic Dialogue Terminal**:
  * A styled chatbot terminal interface for getting in touch. Includes transmission status logs, automated bot replies, Formspree connections, and an absolute state reset option.
* **🌗 Non-Glowish Matte Aesthetic**:
  * Softened and dampened active shadows, variables, and line drop-shadows to ensure high readability, clean contrast, and an executive, professional look.

### 🛠️ Local Assembly & Runtime

To compile and launch the diagnostic console locally:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Arun597134/Arun-M-portfolio-.git
   cd Arun-M-portfolio-
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Engine**:
   ```bash
   npm run dev
   ```
   *The console will initialize at `http://localhost:5173/`.*

4. **Production Build Compilation**:
   ```bash
   npm run build
   ```
